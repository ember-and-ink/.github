# Ember & Ink

Side projects for LLM chat frontends and roleplay, mostly
[SillyTavern](https://github.com/SillyTavern/SillyTavern) extensions. Maintained by
[Matt Nitzken](https://github.com/mjnitz02). Not affiliated with the SillyTavern project.

## Memory

- **[cairn-memory](https://github.com/ember-and-ink/cairn-memory)**: a memory extension
  that keeps a long roleplay's memory as current state plus a sparse set of past events,
  instead of summaries of summaries.
- **[SillyTavern-MessageSummarize](https://github.com/ember-and-ink/SillyTavern-MessageSummarize)**:
  per-message summaries as short- and long-term memory. A fork of qvink's extension.

## Characters

- **[jai-proxy](https://github.com/ember-and-ink/jai-proxy)**: a local archive of
  character cards, saved as SillyTavern-compatible Character Card V3 PNGs, with a browser
  for them.
- **[SillyTavern-CharacterInfo](https://github.com/ember-and-ink/SillyTavern-CharacterInfo)**:
  a read-only view of the current character's card, opened over the chat.
- **[SillyTavern-Tag-Merger](https://github.com/ember-and-ink/SillyTavern-Tag-Merger)**:
  cleans up inconsistent character tags across a whole library using a curated dictionary.

## Chat and UI

- **[SillyTavern-WTrackerLite](https://github.com/ember-and-ink/SillyTavern-WTrackerLite)**:
  a minimal chat-state tracker that doesn't need to switch connection profiles.
- **[SillyTavern-Image-Compressor](https://github.com/ember-and-ink/SillyTavern-Image-Compressor)**:
  converts gallery images to WEBP in the browser, to save disk space.
- **[Guinevere-UI-Extension](https://github.com/ember-and-ink/Guinevere-UI-Extension)**:
  a UI overhaul with theme packs. A fork of Bronya-Rand's extension.
